# AKWF-Akai-MPC-Oscillators

## AKWF Wavetables  converted for Akai MPC Live Oscillators

This is a copy of the [Adventure Kid Free Waveforms](https://www.adventurekid.se/akrt/waveforms/adventure-kid-waveforms/) taken from the original repo [here](https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE) and reformatted to work with the Oscillators feature in AKAI MPC Live Standalone Firmware 3.9 and higher.

The original repo did have a AKAI MPC folder already, but it was not quite in the format required by Oscillators.

Both single cycle and wavetables have been reformatted to work correctly with the Oscillators feature.

- The files have been renamed to be recognized by the firmware.
- Wavetables have been concatenated into single wav files.
- 'format.json' have been added to describe the format.

To use, simply copy the Oscillators folder onto the disk you're using with the MPC.

It may make sense to consult the MPC Standalone Manual for the correct workflow if it doesn't work.

The conversion script is provided for interest only and possibly doesn't work out of the box. IIRC some manual modifications were added.

The original license has been retained.

Enjoy.
